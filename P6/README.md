<h1>📊 Laporan Praktikum Basis Data II - Query Lanjutan</h1>
📌 Deskripsi

Proyek ini merupakan laporan praktikum yang membahas penggunaan query lanjutan dalam SQL untuk pengolahan data yang lebih kompleks dan efisien.

Materi difokuskan pada berbagai jenis subquery dan teknik lanjutan yang umum digunakan dalam pengembangan sistem basis data.

🎯 Tujuan
- Memahami konsep subquery dalam SQL
- Menggunakan subquery dalam berbagai kondisi dan struktur
- Menerapkan query lanjutan untuk pengolahan data yang lebih optimal
- Melatih kemampuan analisis data menggunakan SQL

🧪 Materi yang Dibahas <br>
1. Subquery dasar <br>
2. Subquery dengan banyak kolom <br>
3. Pairwise Comparison Subquery <br>
4. Non-Pairwise Comparison Subquery <br>
5. Subquery dalam klausa FROM <br>
6. Scalar Subquery <br>
7. Correlated Subquery <br>
8. Correlated Subquery pada UPDATE dan DELETE <br>
9. Penggunaan klausa WITH 

🛠️ Teknologi yang Digunakan
SQL (Structured Query Language)
- MySQL / DBMS sejenis
