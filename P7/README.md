<h1>📊 Laporan Praktikum Basis Data II - VIEW (Tabel Virtual)</h1>
📌 Deskripsi

Proyek ini merupakan laporan praktikum mengenai penggunaan VIEW dalam SQL sebagai tabel virtual untuk mempermudah pengolahan dan penyajian data.

Praktikum membahas cara membuat, menampilkan, mengubah, dan menghapus VIEW pada database menggunakan perintah SQL.

🎯 Tujuan
- Memahami konsep VIEW dalam basis data
- Membuat VIEW dari satu maupun beberapa tabel
- Mengelola VIEW menggunakan SQL
- Mempermudah akses dan penyajian data melalui tabel virtual

🧪 Materi yang Dibahas <br>
1. Membuat VIEW dari satu tabel
2. Membuat VIEW dari beberapa tabel
3. Menampilkan isi VIEW
4. Melihat struktur VIEW dengan DESCRIBE
5. Mengubah VIEW menggunakan ALTER VIEW
6. Menghapus VIEW menggunakan DROP VIEW

🛠️ Teknologi yang Digunakan
- SQL (Structured Query Language)
- MySQL / DBMS sejenis
